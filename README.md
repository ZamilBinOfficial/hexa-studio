# HEXA Studio Pro

A sleek, ultra-fast local media downloader and format converter built specifically for video editors and creators.

Download 4K/60FPS video, extract high-bitrate audio, and convert clips with zero ads, limits, or tracking.

---

### ✨ Features

* **Creator-Grade Formats**: Download in pristine MP4 (up to 4K 60FPS) or extract 320kbps MP3 audio.
* **Universal Platform Support**: Works with YouTube, TikTok, Instagram, Twitter/X, and more.
* **Local & Private**: Runs completely on your local machine powered by `yt-dlp` and `FFmpeg`.
* **Dark Matte UI**: Minimal, executive interface designed for seamless background operation.

---

### 🚀 Quickstart

```bash
# 1. Clone repository
git clone https://github.com/ZamilBinOfficial/hexa-studio.git
cd hexa-studio

# 2. Install dependencies
pip install -r requirements.txt

# 3. Start server (default: http://127.0.0.1:5252)
python app.py
```
